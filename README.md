# Rajesh Kannan - Senior Software Engineer Portfolio

This repository contains the interactive portfolio web application for **Rajesh Kannan**, Senior Software Engineer specializing in Angular (v12-17+), Node.js, AWS, and TypeScript.

## 🚀 Technical Highlights

- **Aesthetic Design:** Deep Slate (`#0B0F19`) theme with Electric Cyan (`#00F2FE`) & Royal Blue (`#1E3A8A`) accents, glassmorphism cards, and responsive typography (`Plus Jakarta Sans`, `Inter`).
- **Core Case Studies:** Detailed breakdown of enterprise SDN Controllers, Monitoring as a Service (MaaS), and IZO Multi-Cloud Network (MCN) portals shipped for Tata Communications.
- **Performance Optimized:** Clean Vanilla web implementation with zero external heavy framework runtime overhead, responsive modal dialogs, and dynamic metrics counters.

## 📁 File Architecture

```
rajesh-kannan-portfolio/
├── index.html        # Main DOM structure & case study modal layouts
├── styles.css        # Custom CSS design system, glassmorphism, & responsive grid
├── app.js            # Dynamic metrics counter & interactive modal handlers
└── README.md         # Repository documentation
```

## 🛠️ Local Setup

1. Open `index.html` directly in any web browser, or serve using `npx serve .` or Live Server.
