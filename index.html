Case Study: Ethernet SR-EVPN SDN Controller

Enterprise SD-WAN Path Computation & Circuit Orchestration

Problem Statement

Enterprise network circuit turn-up across SD-WAN endpoints previously required tedious manual router CLI configuration, resulting in high provisioning lead times (2-3 days) and risk of misconfiguration.

Technical Solution

Engineered a high-responsiveness Angular front-end rendering dynamic network topologies using RxJS data pipelines (`switchMap`, `forkJoin`). Integrated directly with Node.js microservices to compute optimal path parameters and execute automated circuit turn-up.

Key Results

  • 40% reduction in manual network engineering effort.
  • Turned up circuits in minutes rather than days.
  • Enforced OAuth2 / Keycloak token security via HTTP interceptors.
